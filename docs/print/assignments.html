A1 搜索与启发式

Task and state

The assignment asks for an action sequence that collects enough crystals and reaches a launch site at minimum total action cost. The existing solver stores position, crystal collection status and remaining rocket jumps in GameState. Two states at the same position may have different futures if their crystals or remaining jumps differ.

Read game_state.py, get_init_state(), is_solved() and perform_action() before tracing the search. A1 returns (next_state, success, error_message) from an action; do not interpret its second return value as a reward.

任务与状态

任务是找到总动作成本最低的动作序列，收集足够水晶后到达发射点。已有代码的 GameState 包含位置、水晶收集状态和剩余火箭跳跃次数。同一位置不一定是同一状态；水晶或剩余资源不同，会改变后续选择。

先读 game_state.py、get_init_state()、is_solved() 和 perform_action()。A1 动作返回 (next_state, success, error_message)，第二项是成功标志，不是奖励。

Trace UCS

Open search_ucs(). The heap stores accumulated path cost g, a tie-breaking counter, the state and a path. visited_cost records the cheapest discovered cost for each state. A strictly cheaper path updates that record and adds a new heap entry; an older, more expensive entry is skipped when popped.

The solver tests the goal on heap removal. Trace the frontier together with the best-cost dictionary: recording only the visitation order hides why a state can appear in the heap more than once. This implementation copies the path list for UCS; its A* implementation instead uses parent links.

读懂 UCS

打开 search_ucs()：堆中记录累计成本 g、打破并列的计数器、状态和路径。visited_cost 保存每个状态目前发现的最低到达成本。发现严格更便宜的路径时，更新记录并加入新堆项；旧的较贵堆项出队时会被跳过。

目标在出堆时检查。手算时同时记录 frontier 和最低成本字典，才能解释为什么堆中可能重复出现一个状态。这份 UCS 复制路径列表，而 A* 使用 parent 链回溯动作。

Trace A star and the heuristic

search_a_star() orders entries by f = g + h. Follow compute_heuristic() into _relaxed_distance(), _line_distance() and the cached crystal-tail calculation. The estimate considers how many samples remain and the final trip to a launch site. The relaxed geometry ignores obstacles and jump restrictions while retaining direction-dependent movement costs and the option of boosting.

Explain the relaxation before claiming a lower bound. Check h(goal)=0, compare sample values with optimal residual costs where available, and examine whether every real action is no more useful in the relaxed problem than the relaxation permits. This archive has not re-proved or re-graded the historical submission.

读懂 A星与启发式

search_a_star() 按 f = g + h 排序。从 compute_heuristic() 继续跟到 _relaxed_distance()、_line_distance() 和带缓存的水晶尾程计算。估计同时考虑还缺多少样本以及最后前往发射点的路程。放松的几何模型忽略障碍和跳跃限制，同时保留方向相关的移动成本和 boost 选项。

说明放松了什么，再论证为什么是下界。检查 h(goal)=0，在能取得最优剩余成本的样本上做比较，并检查放松是否覆盖真实动作的能力。这里收录的是历史代码，没有重新证明或评分。

A small frontier exercise

This is a separate teaching graph, not a CrystalRover testcase. Edges are S→A:4, S→B:1, B→A:1, A→G:2, B→G:9. With nonnegative costs, UCS finds S→B→A→G with cost 4. After expanding B, the best known cost of A becomes 2; the earlier A entry with cost 4 becomes stale.

Try the exercise first. A suitable lower-bound heuristic for this graph is h(S)=4, h(B)=3, h(A)=2, h(G)=0. Write both g and f on each entry rather than confusing the heap priority with the cost of the final path.

一个 frontier 手算例子

这是独立教学图，不是 CrystalRover 测试关卡。边为 S→A:4、S→B:1、B→A:1、A→G:2、B→G:9。UCS 找到 S→B→A→G，总成本 4。扩展 B 后，A 的最低到达成本变为 2，早先成本 4 的 A 堆项成为过期项。

先自己手算。这个图可以使用下界 h(S)=4、h(B)=3、h(A)=2、h(G)=0。堆项同时写 g 和 f，不要把排序优先级误当成最终路径成本。

A2 MDP与策略求解

Read the MDP model

The state records rover position and collected crystals. Rocket jumps are unlimited in A2. Walks, boosts and jumps can have random outcomes; collisions, lava and the storm affect rewards. The task is to obtain a policy over states with a high expected discounted return.

Start at _build_model(): a breadth-first traversal collects reachable states and caches valid actions and transition outcomes. A successor reached with zero probability should not enlarge the reachable state space. Terminal states are retained but not updated as ordinary decision states.

读懂 MDP 模型

状态记录位置和已收集水晶，A2 的火箭跳跃次数不再有限。动作有随机结果，碰撞、岩浆和风暴影响奖励。目标是求出每个状态应采取什么动作的策略，使预期折扣回报尽可能高。

从 _build_model() 开始读：BFS 枚举可达状态，缓存合法动作和转移结果。概率为零的结果不应扩大可达状态空间。终止状态可以保留，但不应作为普通决策状态继续更新。

Audit transition probabilities

_transition_outcomes() enumerates no drift, clockwise drift and counterclockwise drift, together with single and double moves. For a boost it also enumerates each distance. It merges equal successor/reward outcomes. Check that probabilities are nonnegative and sum to 1 for each valid state/action pair, and that early termination stops a multi-move outcome.

For the assignment example with drift 0.3 and double-move 0.2, the six branch probabilities are 0.56, 0.14, 0.12, 0.03, 0.12, 0.03 when grouped as normal single/double, CW single/double, CCW single/double. The two drift directions split the total drift probability equally. The report's Venn diagram itself must be hand drawn.

核对转移概率

_transition_outcomes() 枚举不漂移、顺时针漂移、逆时针漂移，并组合单次和双重移动；boost 还要枚举每次移动的距离。相同后继和奖励的结果会合并。逐个合法状态动作对检查概率非负、总和为 1，以及多次移动途中终止是否及时停止。

题目示例中漂移概率 0.3、双重移动概率 0.2。按普通单次/双次、CW单次/双次、CCW单次/双次排列，六个分支概率为 0.56、0.14、0.12、0.03、0.12、0.03。漂移总概率在两个方向间均分。正式报告要求的 Venn 图仍须手绘。

Trace value iteration

_q_value() sums p * (reward + gamma * successor_value) over outcomes. Terminal successors contribute no future value. _best_action() compares legal actions. vi_iteration() writes updated values directly into vi_values, so later states in the same sweep can use earlier updates; convergence uses the largest change in that sweep against epsilon.

For a separate numerical example, outcomes (p=0.8, r=2, next V=5) and (p=0.2, r=-1, next V=1), with gamma=0.9, give Q=5.18. If the second successor were terminal, its next value would instead be 0 and the result would be 5.00. Keep transition rewards and continuation values separate.

追踪价值迭代

_q_value() 对所有结果累加 p * (reward + gamma * successor_value)。终止后继的未来价值为零。_best_action() 比较合法动作。vi_iteration() 直接改写 vi_values，因此同一轮后面的状态能使用前面刚更新的值；收敛判断使用这一轮最大的价值变化与 epsilon 比较。

独立数值例子：两个结果分别为 p=0.8、r=2、后继价值5，以及 p=0.2、r=-1、后继价值1；gamma=0.9，算得 Q=5.18。如果第二个后继终止，它的未来价值变为0，结果是5.00。进入状态时收到的奖励和此后的价值要分开。

Trace policy iteration

Read pi_iteration(). The archived implementation builds a matrix over nonterminal states and solves (I - gamma P_pi) v = r_pi for the current policy. It then improves the policy using the evaluated values and declares stability when no action changes.

A small number of outer policy iterations does not by itself establish a faster runtime. Record total convergence time and the kind of policy evaluation being used. Cached transitions and a smaller reachable-state set reduce repeated work; do not describe in-place updates or linear algebra as the only optimisations if the report asks for additional ones.

追踪策略迭代

读 pi_iteration()：已有代码在非终止状态上建立矩阵，求解 (I - gamma P_pi) v = r_pi 得到当前策略的价值；再据此改进策略，所有动作都不再变化时判定稳定。

外层策略迭代次数较少，本身不能证明总耗时较低。记录完整收敛时间，并说明策略评估的方式。缓存转移和只保留可达状态可减少重复计算；报告要求额外优化时，要说明原地更新或线性代数之外具体做了什么。

将辅助指南、评分表和报告放在一起核对。可视化中的价值与箭头应对应明确的水晶状态切片和迭代轮数。历史文档按原样保存；本次整合没有重新运行或确认其中全部实验结论。

Read the training episode

Follow ql_initialise(), ql_train_episode() and ql_select_action(). The reference starts each episode at get_init_state(), chooses only legal actions, obtains the actual reward through perform_action() and updates its table. Its public evaluation method is deterministic and does not update learned values.

For a nonterminal transition the target in this implementation is reward + gamma * max_next_Q; for a true terminal successor it is reward. Trace a single numeric update and check that a time or reward cutoff does not accidentally make an ordinary successor into an absorbing state.

按一次训练episode读代码

顺着 ql_initialise()、ql_train_episode()、ql_select_action() 读。参考实现从 get_init_state() 开始一幕，只选合法动作，通过 perform_action() 取得真实奖励，再更新表格。公开的评估选择方法是确定性的，不更新已学习的数值。

这份实现对非终止转移使用目标 reward + gamma * max_next_Q，对真正终止的后继只使用 reward。自己手算一次更新，检查步数或回报截断有没有被误写成普通后继的吸收终止。

Inspect the 21 feature coordinates

FEATURE_NAMES defines a fixed order. fq_get_features() returns action-type and direction indicators, map-distance descriptors, nearby terrain and collection-status descriptors. The entire vector is divided by max(1, L2 norm). fq_weights starts at zero and is changed only during training; a Q-value is the dot product of the weights and the feature vector.

For the report parts that allow AI only with explicit verification, reproduce several feature values from the map and record what you actually checked. Keep the feature definitions, normalisation and recorded weights aligned with the version of code you finally use.

核对21个特征坐标

FEATURE_NAMES 规定固定顺序。fq_get_features() 输出动作类型与方向、地图距离、邻近地形和收集进度描述，整条向量除以 max(1, L2范数)。fq_weights 从全零开始，只在训练中修改；Q 值是权重与特征的点积。

报告中标记“允许 AI 但需明确验证”的小问，要根据地图重算几个特征值，并记录自己实际检查了什么。最终代码的特征定义、归一化方法和报告中的权重表必须对应同一版本。

Use the three recorded experiments

baseline contains eight runs: QL and FQ for L1–L4 using each algorithm's official budget. learning_rates contains three L1 QL runs with fixed alpha values 0.1, 0.2 and 0.4. comparison contains four runs, with the same training-budget limits, learning threshold and evaluation protocol for QL and FQ on L1 and L3.

The training plots show a moving mean over 50 episodes, including exploration. Greedy checkpoints use 50 separate evaluation trials. Final summaries record 1000 evaluation trials. A missing threshold-crossing value means not reached; it is not the final training step. The tables below reproduce recorded numbers without supplying the report's restricted interpretations.

使用三组已有实验

baseline 有八组：L1–L4 的 QL/FQ，分别使用各自官方预算。learning_rates 有三组 L1 QL，固定学习率为 0.1、0.2、0.4。comparison 有四组：L1/L3 的 QL/FQ 使用相同的训练预算限制、学习阈值和评估流程。

训练曲线是含探索行为的最近50幕回报平均；贪心 checkpoint 使用另外50次评估；最终汇总记录1000次评估。达标数据缺失表示未达到阈值，不能用最后训练步数替代。下方按原记录展示数值，不代写报告中禁止 AI 的结果解读。
