# 选择题答案与解释

**Q01 D**：理性与结果保证不同，也允许有限算力。

**Q02 C**：能观察当前状态，不代表下一状态由动作唯一确定。

**Q03 B**：状态应保留预测未来所需的信息。

**Q04 A**：搜索树区分路径，状态图可合并重复状态。

**Q05 D**：MCTS 是可用模型模拟器的在线规划例子。

**Q06 C**：BFS 按深度，不按边权和排序。

**Q07 B**：只有最低 g 目标出队时才能据排序论证最优。

**Q08 A**：一致性使 f 沿路径不减，已扩展状态无需重新打开。

**Q09 D**：max 仍不超过真实成本，求和可能重复计数。

**Q10 C**：f_new=f_old+5；要对目标也同样加，且比较相同实现。

**Q11 B**：量词为 ∀x∃y。

**Q12 A**：Z 的支持可能正是刚删掉的 X 值。

**Q13 D**：两色三角形是 arc-consistent 但无解的反例。

**Q14 C**：MRV 选最少剩余值变量；LCV 选最少限制邻居的值。

**Q15 B**：e 为弧/约束数量量级，d 为最大域大小。

**Q16 A**：独立不等于互斥，联合可以非零。

**Q17 D**：例如 [0,.5] 上均匀密度为 2。

**Q18 C**：当前状态为行，下一状态为列。

**Q19 B**：先把每种结果映射为效用，再按概率加权。

**Q20 A**：等比级数 3/(1−.5)=6。

**Q21 D**：OR 选动作，AND 覆盖环境结果。

**Q22 C**：强计划要求每个结果都有通向目标的后续方案。

**Q23 B**：max/min 对应不同的决策/对手假设。

**Q24 A**：可能几乎必然成功，但不保证每一结果序列都有限结束。

**Q25 D**：不确定动作结果使分支策略成为必要。

**Q26 C**：价值是数，确定策略返回动作。

**Q27 B**：原地 VI 是另一种更新方案，手算结果不同。

**Q28 A**：(I−γPπ)Vπ=rπ。

**Q29 D**：合并到同一后继状态的概率必须相加。

**Q30 C**：exit 发奖模型不能当成进入格子发奖模型。

**Q31 B**：先在已有树选择，再扩展，再 rollout，最后更新路径统计。

**Q32 A**：bonus 与 1/√n 成比例。

**Q33 D**：(4×2+7)/5=3。

**Q34 C**：有限采样有误差，不能从 anytime 推出最优保证。
