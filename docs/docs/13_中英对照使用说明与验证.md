# 中英对照版使用说明

1. 打开 `study/index.html`，右上角选择 **English + 中文**，按英文正文→中文解释的顺序学习。
2. 掌握后切换 **English only**，闭卷重做题目，用英文写出模型、公式、代入、中间步骤和结论。
3. 在 **Exam English** 查看18个指令词、82个术语和15类答题句式。句式是推理支架，不能代替实际计算。
4. 模拟卷页面可打开 **English paper, no solutions**，打印纯英文无答案卷。英文答案及评分点另存于 `docs/12_Mock_A_English.md` 和 B。
5. 新版 PDF 是 `COMP3702_中英对照复习主册.pdf`（71页）与 `COMP3702_中英对照题库与模拟卷.pdf`（58页）。原中文 PDF 仍保留。
6. 阅读模式控制已翻译的讲义、题目、解析和主要实验叙述；部分导航、控制标签和原课程图片保留双语或原文。
