## 动效行为

卡片光晕为半径240像素的灰白渐变，中心透明度7%；边缘渐变仅作用于1像素边框。跟随效果仅对精细指针启用，更新合并到 requestAnimationFrame。标题和正文没有位移动画或模糊滤镜。交互卡片禁用意外拖动产生的文字选区，正文仍可选取。

数字的真实文本在状态变化时立即更新；动效只显示一个 `aria-hidden` 视觉层。首次出现使用当前保存值，不从零播放。同一个统计键在切页后复用上次显示值；快速再次修改时从正在显示的值继续。动效模块不读写 localStorage。即使缺少动效API或动效样式，真实数字仍可读，视觉副本默认隐藏。

减少动态设置变化、页面转入后台和打印前，会停止插值并恢复精确文本。打印样式再次强制显示真实数字、隐藏视觉层。静态键盘焦点高亮与触屏按下反馈独立于跟随效果。

## 验证边界

本机是Windows，Mac对应的是常见窗口尺寸与字体回退检查，没有在Safari或真实Mac硬件上运行。手机检查使用响应式视口，触摸分支另有逻辑检查。

浏览器工具只允许HTTP/HTTPS，拒绝直接访问file协议。因此浏览器交互使用本机HTTP服务器；离线交付通过本地脚本、样式、图片和文件链接的完整性核对，未绕过协议限制。打印回退通过逻辑与CSS核对，没有调用实体打印机。
