# A3：从第一次操作，到能解释代码

打开 `study/a3/index.html`，不需要安装依赖或联网。也可以从全站导航“A3 从零学”进入同一单元。建议第一遍只看中文，先按按钮，再读旁边十行左右的 Python；不必一次读完整个文件。

## 先分清页面上的三类材料

- **课堂模型**：第一课小地图、四动作Q表、三维权重算术和epsilon骰子。用于弄懂概念，参数明确写在页面上；不是官方隐藏动力学。
- **真实代码回放与特征**：参考 `assignments/a3/code/solution.py`。24步回放来自公开 `perform_action` 接口，为教学设每幕12步、总预算24步。地图特征按同一实现计算，并逐项对照244组Python输出。地图动画连接观察到的起点与终点，不重建中间运动轨迹。
- **原始训练记录**：保留此前15组实测CSV。曲线抽取至多180个实际点；每点的50幕平均来自完整CSV，不能对抽样点重新求平均。

## 按这个顺序动手

1. **先让机器人走起来**：点右六次，观察坐标、收集标记和累计奖励。状态就是“当前位置＋收集情况”；动作是发出的一条指令；奖励是环境返回的一个数；一幕是从开始到结束的一段经历。撞墙仍是一次动作，但位置可能不变。先认识变量、列表、字典、函数、if与for。对应 `__init__` 和 `ql_train_episode`。
2. **给动作记一张分数表**：四个负数里找最大值；再切换“坐标相同、水晶不同”的状态，观察为什么是另一行。Q是长期回报估计，负数仍选择较大者。页面是四动作课堂表；实际代码每行12个槽位，按合法动作筛选。对应 `ql_initialise`、`ql_select_action`。
3. **亲手改一个Q值**：先预测，再点六个小步骤。默认旧Q=1、reward=-2、gamma=.9、alpha=.2、下一状态最大Q=5，新Q=1.3。勾选终止后，新Q=.4，后继值不再参与。终止状态与幕步数/预算截断不同。对应 `ql_train_episode`。
4. **把步骤连成一幕**：拖到真实样本，按“下一小步”，追踪 `state → action → next_state,reward → target → Q → state`。第13个样本开始新一幕，位置重置，但表不清空。展开epsilon骰子，分别看训练探索和评估贪心；骰子不修改真实回放。对应 `_epsilon`、`_training_action`、`ql_train_episode`。
5. **把地图变成21个数字**：先选L1，点一个安全格，再选动作。逐个点向量坐标，观察原始值、范数和最终值。勾水晶改变目标，点陨石坑时只能选择jump。地图距离是描述特征，不是隐藏的转移概率模型。对应 `fq_get_features`、`_bfs_map_distances`、`_ray_position`。
6. **让权重改变**：先看三维小算术，算点积，再算target、误差和每项变化；最后点“写入”，下一次用新的权重。切换21维模式，使用上一课选出的真实特征，但权重仍是课堂演示值。对应 `_dot`、`fq_train_episode`。
7. **看懂保存的记录**：先看十个奖励的小平均数，再拖动真实曲线。原始单幕奖励、50幕平均和累计训练步数是不同量。训练回报含探索，不能当成另跑的贪心评估均值。对应实验脚本 `moving_average`。
8. **自己讲一遍，再自己实现**：用页面笔记写“输入是什么、哪一行改变了什么、输出是什么”。闭卷能讲再标记掌握。按下一份文档的9个里程碑开发自己的版本；勾选不是Git提交。
